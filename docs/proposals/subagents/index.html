Sub-agents in SHOUT: design proposals

Static mocks built on the app's real stylesheet. One scenario throughout: SHOUT fans an audit of the ledger importer out to three agents.

Chat A

Agent group card

One card per fan-out, sitting in the transcript where the run card sits today. Each agent is a row: state, name, brief, and what it is doing right now. A row opens in place to show that agent's steps and its report. Approvals surface on the row that needs them.

Chat B

Roster on the composer, threads in the dock

The transcript stays clean. Running agents live as pills above the composer, so their state is visible wherever you have scrolled. Clicking a pill opens that agent's own thread as a dock tab, using the split and tab system that already exists. Each thread is a real chat: you can read it and steer it.

Flow A

Agents as frames that fold

Flow already draws a dashed frame around a run. An agent is the same idea: a frame holding its own hubs and tools, placed side by side with its siblings so parallel work reads as parallel. When an agent finishes, its frame folds into a single card carrying the report. Edges fan out from the parent's hub and gather again at the step that reads the results.

Flow B

Fleet card for wide fan-outs

Frames stop working past four or five agents. Beyond that, the fan-out becomes one card holding a tile per agent. Each tile shows state, current step, and a strip of its steps so far. Clicking a tile opens that agent's frame on its own canvas, or its thread in the dock.

Inspector

A lane per agent

The Activity minimap already has lanes for You, SHOUT, Model, ALLEN and Tools. Agents add lanes beneath them. Each lane shows the agent's lifetime as a bar, with ticks for its steps. Overlap is visible at a glance, and so is an agent that has gone quiet.

What else the Inspector gains
  • An Agents list beside Runs, each row with state, steps, tokens and an open-in-tab button.
  • A per-agent filter on the Events view, driven by the new agent field on every event.
  • Token and time totals rolled up per agent and for the whole fan-out, since cost is the first question people ask about sub-agents.
